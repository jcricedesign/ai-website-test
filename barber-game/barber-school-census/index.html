    How it was built

    • Federal data: the Department of Education's IPEDS 2023–24 completions survey, filtered to schools that reported barbering graduates (program code 12.0402).
    • State data: each state board's own school list, as a download, web page, PDF or dashboard. Lists were read in November 2026.
    • Matching: state and federal rows are matched by state, ZIP code and name similarity. A school listed under a legal name in one source and a trading name in the other can appear twice.
    • Mixed lists: California, Ohio, New Jersey and West Virginia list cosmetology and barber schools together. Those rows count as barber programs only when the name says barber or federal data shows barber graduates.
    • Known gaps: Texas's state file misses large barber colleges that appear in federal data. Connecticut's list dates from 2016 and South Dakota's from 2022. Blocked states use bot checks or refused automated downloads.

    Next steps

    1. Missouri: download the free list from the state's MOPRO "Downloadable Listings" page by hand.
    2. Blocked states (Arizona, Georgia, Alaska, Massachusetts, Mississippi, New Mexico, Rhode Island): open the board pages in a normal browser and save their lists.
    3. Lookup-only and paid states: file public records requests, starting with the largest (Florida, New York, Georgia, Pennsylvania).
    4. Decide on scope: whether prison and high-school programs belong in a public directory, since they're licensed but not open to the public.
